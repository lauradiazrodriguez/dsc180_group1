Introduction

Many variables in financial markets move together. However, these patterns do not necessarily imply causal relationships. In many cases, multiple variables change simultaneously due to shared underlying factors.

Because of this, simple correlation-based feature selection can easily include spurious predictors. Models built on these relationships may perform well on training data but fail to generalize to unseen data.

In this project, we explore whether causal discovery methods can identify more meaningful predictors in financial time-series data. Using the PCMCI algorithm, we focus on lagged causal relationships while filtering out instantaneous noise. This allows us to build a regression model that is simpler, more interpretable, and more robust than a naive baseline model.

Data

Our dataset combines macroeconomic indicators and financial market variables collected from two public data sources. The data spans from 2000 to 2025, capturing long-term economic conditions and market dynamics.

Macroeconomic Variables (FRED)

  • Unemployment Rate (UNRATE)
  • Consumer Price Index – Inflation (CPIAUCSL)
  • Federal Funds Rate (FEDFUNDS)
  • Yield Curve Spread (T10Y2Y)
  • Market Volatility Index – VIX (VIXCLS)
  • High Yield Credit Spread (BAMLH0A0HYM2)

Market Variables (Yahoo Finance)

  • Crude Oil Futures (CL=F)
  • Gold Futures (GC=F)

  • Technology Sector ETF (XLK)

These variables capture both macroeconomic conditions and financial market activity, allowing us to analyze causal relationships across different parts of the financial system.

Methods

Data Preparation & Stationarity

Financial time-series often exhibit strong trends that violate the stationarity assumption required for causal discovery. To address this issue, price series were transformed into log returns to stabilize the mean and variance over time. All variables were then standardized to place them on comparable scales and ensure reliable statistical testing in the PCMCI causal discovery pipeline.

Chronological Train-Test Split

Because financial time-series data are inherently time-ordered, we used a chronological train–test split rather than random sampling. Random shuffling can introduce data leakage by allowing future observations to influence past predictions. Using a chronological split ensures that the model is trained only on past observations and evaluated on future data.

Causal Discovery using PCMCI

To discover causal relationships between financial variables, we applied the PCMCI algorithm from the Tigramite framework. PCMCI is designed for time-series data and identifies causal links while accounting for lagged dependencies between variables, allowing the model to distinguish meaningful temporal relationships from simple correlations.

Hyperparameter Optimization

We optimized key PCMCI parameters including the maximum time lag and significance threshold. An elbow-style analysis of partial correlation strength across time lags suggested that most causal influence occurs within one day. We then conducted a grid search over multiple parameter combinations and evaluated their performance using regression models and test mean squared error.

Interactive Causal Graphs

Explore the difference between the baseline PCMCI configuration and our domain-specialized parameters. The baseline graph suffers from high saturation, producing many spurious correlations, while the specialized graph filters noise to highlight targeted lagged causal relationships.

We compare two variations of the PCMCI algorithm using the ParCorr conditional independence test:

  • Baseline Model: Default hyperparameter settings (Tau = 5, Alpha = 0.05).
  • Domain-Specialized Model: Domain-informed parameters (Tau = 2, Alpha = 0.01) designed to reduce false positives and capture meaningful lagged causal dependencies.

Results & Discussion

The baseline PCMCI configuration (Alpha = 0.05, Tau = 5) produced a highly saturated causal graph that primarily reflected general market co-movement rather than clear causal relationships. As the lag window increased, training error decreased while test error increased, indicating clear signs of overfitting.

To address this issue, we applied domain-informed parameter tuning to the causal discovery process. By restricting the time lag and relaxing the significance threshold (Tau = 1, Alpha = 0.2), the domain-specialized PCMCI model produced significantly cleaner causal graphs with far fewer spurious relationships.

Model Complexity (Predictors)

To evaluate the usefulness of the discovered causal structures, we used the identified parent variables as predictors in downstream linear regression models. Across the 13 financial variables analyzed, the baseline configuration identified an average of 17.5 predictors per target variable. In contrast, the domain-specialized model reduced this to only 3.8 predictors on average.

This substantial reduction in predictors reflects a much simpler and more interpretable causal structure. By incorporating domain knowledge into the causal discovery process, the model was able to filter out many spurious relationships that appeared in the baseline configuration.

Prediction Error (MSE)

Despite using far fewer predictors, the specialized model achieved slightly better predictive performance. The baseline configuration produced an out-of-sample MSE of 0.895, while the specialized model achieved a lower MSE of 0.877.

Overall, the domain-specialized model improved predictive performance by approximately 2% while using substantially fewer predictors. This result suggests that incorporating domain knowledge into causal discovery can both simplify the resulting graph structure and improve downstream predictive modeling.

Conclusion

We summarize our key findings by emphasizing the importance of careful hyperparameter selection and domain knowledge in financial causal discovery. The optimized pipeline produces dynamic causal graphs (DCGs) that are far more interpretable for macroeconomic environments and result in out-of-sample predictive models that generalize reliably.
